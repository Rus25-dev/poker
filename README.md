# Покер с друзьями

Онлайн-покер для компании друзей: каждый играет со своего телефона, вход по коду стола. Работает на GitHub Pages и устанавливается на главный экран как приложение (PWA). Своего сервера не нужно.

**Играть:** https://rus25-dev.github.io/poker/

## Режимы
- **Холдем** (No-Limit), **Омаха** (пот-лимит, 4 карты), **Ананас** (3 карты, одна сбрасывается после торговли до флопа).
- **Кэш-игра** с докупкой и **турнир** (Sit&Go): растущие блайнды, анте с 4-го уровня, ребай в первые уровни, призовые места.
- Тренировка с ботами трёх характеров без интернета.

## Подсказки
- Текущая комбинация, сила стартовой руки.
- Шанс выиграть **против вероятных диапазонов** соперников (учитываются рейзы до флопа и ставки на улицах) и против любых карт.
- Ауты и шанс их прихода, шансы банка, короткий совет; вероятности комбинаций к риверу.
- **Режим тренера**: рекомендуемое действие, размер ставки и объяснение, кнопка подсвечивается.
- В ананасе — какую карту лучше сбросить.
- При олл-ине проценты каждого игрока на столе.
- **Разбор раздач**: история последних 40 раздач, ошибки с оценкой упущенных фишек (EV) и пошаговый повтор.
- **HUD**: VPIP, PFR и агрессия соперников прямо над их местами.
- Хост может выключить подсказки для всего стола.

## Надёжность и честность
- **Смена хоста**: если телефон хоста пропал, стол автоматически переезжает к следующему игроку (незаконченная раздача отменяется, фишки возвращаются на начало раздачи).
- Переподключение без потери места; восстановление стола у хоста после перезагрузки.
- **Проверяемая тасовка**: хост публикует хеш своего сида до раздачи, игроки добавляют свои сиды, после раздачи телефон каждого игрока сам пересчитывает колоду и проверяет карты. Подтасовать колоду хост не может (подсмотреть карты технически подкованный хост всё ещё может — это предел игры без сервера).
- Свой TURN-сервер в настройках — если через мобильный интернет не соединяется.

## Удобство
- Анимации раздачи, фишек и вскрытия, синтезированные звуки, вибрация, уведомление о ходе в фоне.
- Темы сукна, рубашки, четырёхцветная колода, аватарки (эмодзи или фото).
- Русский, казахский и английский языки.
- Таймер хода и запас времени, «отойти от стола», «показать карты», предварительные действия.
- Раскладка для телефонов (включая маленькие экраны) и горизонтальная — для планшетов и компьютеров.

## Как играть
- Хост: «Создать стол» → настройки → «Открыть стол» → «Пригласить» → при желании «＋ Бот» → «Начать игру».
- Друзья: открыть ссылку или ввести код → «Войти».

## Разработка
Чистый JavaScript (ES-модули), без сборки. Локально: `python3 -m http.server` в папке проекта.

Тесты:
- `node test/engine.test.js` — оценка рук (в т. ч. омаха), сайд-поты, пот-лимит, честная тасовка, снимок для смены хоста, тысячи раздач ботами во всех режимах с проверкой сохранения фишек.
- `node test/ui2.test.cjs <папка>` — три «телефона» в браузере: проверка честности, смена хоста, ананас, омаха с тренером, разбор, планшет (нужен Playwright).
- `node test/small.test.cjs <папка>` — компоновка на маленьком экране.
