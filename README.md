# Покер с друзьями

Техасский холдем (No-Limit) для игры с друзьями онлайн, каждый со своего телефона. Работает как веб-приложение на GitHub Pages и устанавливается на главный экран (PWA).

## Возможности
- Онлайн-стол на 2–6 игроков по коду комнаты или ссылке; связь напрямую между телефонами (WebRTC, PeerJS), свой сервер не нужен.
- Кэш-игра с докупкой и турнир с растущими блайндами, местами и итогами.
- Боты трёх характеров (осторожный, сбалансированный, агрессивный) — за столом с друзьями и в офлайн-тренировке.
- Подсказки: текущая комбинация, шанс выиграть (Монте-Карло), ауты и шанс их прихода, шансы банка с советом, вероятности комбинаций к риверу, сила стартовой руки; при олл-ине — проценты каждого игрока на столе. Хост может выключить подсказки.
- Чат, эмодзи-реакции над игроками, журнал раздачи.
- Статистика и рейтинг Эло (по турнирам), VPIP/PFR, стиль игры, итог по фишкам.
- Таймер хода, предварительные действия (Чек/Фолд, Колл любой), переподключение без потери места, восстановление стола после перезагрузки у хоста.

## Публикация на GitHub Pages
1. Создайте репозиторий (например, `poker`) и загрузите в него содержимое этой папки.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту игра будет по адресу `https://<логин>.github.io/poker/`.

## Как играть
- Хост: «Создать стол» → настройки → «Открыть стол» → «Пригласить» (отправить ссылку) → при желании «＋ Бот» → «Начать игру».
- Друзья: открыть ссылку или ввести код → «Войти».
- Стол живёт на телефоне хоста: хосту нельзя закрывать приложение во время игры (экран не гаснет автоматически). Если закрыл — при повторном открытии появится «Восстановить стол» с тем же кодом.

## Разработка
- Чистый JavaScript (ES-модули), без сборки. Локально: `python3 -m http.server` в папке проекта.
- Тесты движка: `node test/engine.test.js` (оценка рук, сайд-поты, тысячи раздач ботами с проверкой сохранения фишек).
